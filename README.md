# astrbot_plugin_chai

北科大（iBeiKe）**无课教室**查询插件：查今天/明天哪些教室空着，直接出图。

## 指令

| 指令 | 别名 | 说明 |
| --- | --- | --- |
| `/wk` | `/无课` | 查询**今天**的无课教室 |
| `/mrwk` | `/明日无课` | 查询**明天**的无课教室 |

返回一张图片：按楼栋分组，每栋楼一张表，**横轴 1-6 大节，纵轴楼层**，
没有空教室的楼层和楼栋不渲染。

## 输出示例

```
9月15日（周二）无课教室
逸夫楼
        一大节   二大节   三大节   四大节   五大节   六大节
7层      704                       704
9层      901、903  901、903、904    901、903  901、903、904
信息楼
...
```

（实际以图片形式发送；字体目录为空等情况下会自动降级为上面的纯文本。）

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `refresh_time` | string | `07:00` | 每日自动刷新的时间，24 小时制 `HH:MM` |

## 字体

在以下路径放置一个中文字体即可，同时支持常规与粗体，多个文件按文件名排序取第一个：

```
data/plugin_data/astrbot_plugin_chai/fonts/
```

## 数据来源

本插件通过学校公开信息接口查询空闲教室信息。请遵守学校规定及接口使用条款，请勿高频请求或用于商业用途。
